Is A local-first desktop workspace for multi-Agent collaboration. A working group built from the Agent CLIs you select. Shared context, authorized execution, peer review, and local run history. Workspace writes as opt-in workflow controls. Open source under the Apache License 2.0. Isn't Not a hosted Agent fleet or general Agent framework. Not automatic participant selection from a larger roster. Not a guarantee that every task finishes without your input. Not an operating-system sandbox — writes happen through your shell. What is Meldwork? Meldwork is a local-first multi-Agent collaboration workspace for macOS. It brings your existing Agents into one working group to share context, discuss approaches, carry out authorized work, and check results. You choose the participants, set goals and permissions, and step in when information or key decisions are needed. Does Meldwork send my code to a remote service? Meldwork stores conversations and coordinates work locally. Selected Agents may send prompts, attachments, or Skills to the model provider configured in their own CLI. Local-first describes where Meldwork stores and coordinates the work; it does not mean the model runs offline. Which General Agents does Meldwork support? Thirteen today — Codex, Claude Code, Gemini CLI, Qwen Code, Kimi Code, MiMo Code, OpenCode, OpenCodeReview, Hermes, Zcode, Pi Agent, OpenClaw, and WorkBuddy. Approved Agent Connectors can be added through the Agent Connector SDK; custom executables use the desktop custom-Agent path. What does Auto Discussion actually do? Selected Agents start with independent proposals, then discuss differences, request peer contributions, carry out authorized work, and check deliverables. A delivery owner judges progress and whether more work or a user decision is needed. You do not need to direct every round, but missing information, permissions, or key decisions can still require your input. How is Meldwork different from a terminal or IDE? Meldwork adds task-level collaboration across selected Agent CLIs: shared context, peer discussion, requests for further contributions, authorized execution, and review of deliverables. This reduces the work of relaying replies and coordinating next steps yourself. Collaboration history and run state stay local so you can revisit progress and blockers. Do I still need to intervene? You choose the Agents, goal, context, and permissions. Auto Discussion lets Agents advance the work without you directing each turn, but missing information, permission requests, or key tradeoffs may require your input. Workspace writes are opt-in. Check important deliverables before using them; peer review does not guarantee correctness. Is Meldwork free? What's the license? Open source under the Apache License 2.0.
