Requirements macOS, Linux, or Windows (WSL2) Node.js 20+ & pnpm 10+ Claude or Codex credential Docker (Desktop or Engine) In the News FAQ What is NanoClaw? NanoClaw is a lightweight, open-source personal AI agent that runs on your own machine. It connects to the messaging apps you choose, runs every active session inside an isolated Docker container, and routes credentials through OneCLI's Agent Vault by default so agents never hold raw API keys. Claude is the default provider; Codex, OpenCode, and Ollama can be configured per agent group. How is NanoClaw different from OpenClaw? NanoClaw keeps one Node.js host process and a focused, auditable codebase, then runs every active agent session behind OS-level container isolation. Channels and alternative providers are installed as skills, so your fork carries only the integrations you choose. Is NanoClaw secure? Security is a core design principle. Every active session runs in its own unprivileged Docker container and sees only the files you give it. By default, credentials stay in OneCLI's Agent Vault and never enter the container. Egress lockdown, mount rules, sender policies, and human approvals can narrow the blast radius further. Do I need to know how to code to use NanoClaw? No. Run bash nanoclaw.sh and the installer handles dependencies, provider credentials, containers, and pairing your first channel. For later changes, a coding agent such as Claude Code, Codex, or OpenCode can apply NanoClaw's skills. Comfort with a terminal and git clone is expected. Is NanoClaw free? NanoClaw is free and open source under the MIT license. Your agent provider may charge for model usage: Claude accepts an API key or Claude subscription, Codex accepts a ChatGPT subscription or OpenAI API key, and OpenCode uses the providers you configure. Local Ollama models can run without a hosted-model bill. What messaging apps does NanoClaw support? WhatsApp, WhatsApp Cloud, Telegram, Discord, Slack, Microsoft Teams, Mattermost, iMessage, Signal, Matrix, Google Chat, Webex, Linear, GitHub, WeChat, Delta Chat, Emacs, and email via Resend. Channels are installed on demand with /add-<channel> skills, so you only carry the adapters you use. Run one or many, each wired to its own agent or sharing one. What container runtimes are supported? Docker is the only supported container runtime. It works on macOS, Linux, and Windows through WSL2. Can I run NanoClaw on Linux or Windows? Yes. NanoClaw runs on macOS, Linux, and Windows through WSL2. Bring git and a credential for the provider you choose; bash nanoclaw.sh installs Node.js, pnpm, Docker, and OneCLI when they are missing. How do I set up and configure NanoClaw? Clone the repo and run bash nanoclaw.sh. The script installs dependencies, prepares Docker and OneCLI, asks whether Claude or Codex should power the first agent, stores that provider's credential in the vault, and pairs a local CLI or messaging channel. For later changes, run the same repository skills from Claude Code, Codex, or OpenCode. How does NanoClaw compare to other AI agent frameworks? NanoClaw is for people who want a personal AI assistant they own and control. One Node.js host process coordinates isolated, per-session Docker containers. Claude is the default provider; Codex can be selected during setup, and Codex, OpenCode, or local Ollama models can be configured per agent group. Is NanoClaw open source? Yes. NanoClaw is fully open source under the MIT license. The entire codebase is available on GitHub, and contributions are welcome. The project encourages forking and customization.
