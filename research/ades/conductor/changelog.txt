Conductor changelog https://www.conductor.build/changelog Product updates, improvements, and fixes for Conductor. en-US Fri, 20 Nov 2026 00:00:00 GMT Conductor 0.98.0: See where your usage goes https://www.conductor.build/changelog/0.98.0-see-where-your-usage-goes https://www.conductor.build/changelog/0.98.0-see-where-your-usage-goes Fri, 20 Nov 2026 00:00:00 GMT The new Usage page shows your chats, estimated cost, and tokens across local workspaces for the last 7, 30, or 90 days, broken down by model and by workspace. Open it from the Usage button in the sidebar footer or in Settings → Usage. The Usage page showing chats, estimated cost, and tokens over 30 days, broken down by model and workspace Themes are also out of experimental. In Settings → Appearance, pick a preset like Dracula or Nord, make your own theme, or ask an agent to change it for you. Improvements Running background tasks now show above the composer, with each task's elapsed time and a button to stop it. The Artifacts tab has a new Background tasks tile that lists finished background tasks by chat. Open a task to see its output or a read-only view of the agent's work. Conductor starts up faster. You can now open workspaces in Rex. Agents in local workspaces can now rename workspaces. Fixes Fixed the loading screen showing the dark theme at launch when you use light mode or another theme. Fixed Conductor freezing for a few seconds when playing the completion sound. Fixed the cursor jumping to the end when typing in the middle of a custom answer to an agent's question. Fixed a queued message with a skill mention showing raw markup after you edited it. Fixed repository settings and "Add action" sometimes opening Settings → General instead. Fixed long files in the diff viewer appearing cut off after switching between files. Fixed loading animations not appearing when you're offline. Conductor now recovers automatically when its background service stops unexpectedly. Misc Repository settings now open on a General page, with a larger icon picker. Removed the Next.js and gstack templates from Create project. New projects now start as an empty Git repo. The workspace info card now labels its Open in dropdown. Conductor 0.97.0: First class artifacts https://www.conductor.build/changelog/0.97.0-first-class-artifacts https://www.conductor.build/changelog/0.97.0-first-class-artifacts Thu, 19 Nov 2026 00:00:00 GMT Agents in local workspaces can now make artifacts: HTML pages that show inline in the chat. In a chat, @ the artifact name to explicitly invoke it. Create (or disable) artifact templates in Settings → Artifacts. A sequence diagram artifact showing how Conductor creates a worktree, inline in the chat You can also reply to any part of a chat. Highlight text in the transcript to add a comment pill quoting it to the composer. Highlighting text in a chat message to reply to it Added Dracula, Gruvbox, Tokyo Night, Nord, and Catppuccin to the experimental app themes. You can share a custom theme by copying and pasting its colors, or ask an agent to change your theme for you. Conductor with a custom theme applied The Conductor Passport now shows your cities on a 3D globe you can spin, zoom, and fly around. The Conductor Passport showing visited cities on a 3D globe Improvements Agents in local workspaces can now search your chats for what was said in them. Text you add to chat with ⌘L now keeps its formatting, so tables, code blocks, lists, and headings arrive as markdown instead of flattened text. Agent messages written mid-turn now fold into the tool call group, with the latest message and tool call pinned while the agent works. When one agent messages another chat, the message now reaches it during its current turn instead of waiting for the turn to end. When a chat fails while using a custom Claude Code or Codex executable older than Conductor's bundled one, the error now says so and links to the setting.
