Source · github.com/stablyai/orca · Oct 26, 2026 Yes With a condition No Best in row A FEW DETAILS Questions, answered. What is Cloudroom? Cloudroom is a platform for running AI coding agents in the cloud, each in its own sandbox. It manages agent execution and session history while you use your own tools and model accounts. One app runs your agents on your computer or in the cloud. Can I use Cloudroom today? Yes. Click Get started, create your account, and download the app. Ultra teams start with an onboarding call with David. Can my AI agent install Cloudroom for me? Yes. Tell Claude Code, Codex, or any coding agent on your computer: "Set up Cloudroom for me." It follows https://www.cloudroom.dev/setup.md to download and install the app. You only create your account when the app opens. Is Cloudroom free? Yes. Cloudroom gives you cloud agents for free. The Free plan includes 3,000 Cloud Credits every 30 days, and local agents are free forever. Pro ($50/month), Super ($150/month), and Ultra ($500/month) give you more. You bring your own model subscriptions. Cloudroom is also fully open source, so you can read the code or run it yourself. Which AI coding agents does it support? Local threads run Claude Code, Codex, Pi Agent, and any ACP agent, such as Cursor, OpenCode, Grok, Hermes, Devin, and Droid. Cloud threads run 10: Claude Code, Codex, Pi Agent, Cursor, OpenCode, fx, Hermes, Devin, Droid, and OpenClaw. Do I need to change my model subscription? Cloudroom is designed to work with your own model accounts and coding subscriptions. Your harness connects to its model provider directly. Cloudroom does not replace your inference provider or bill you for its model calls. Will my agents work when my laptop is closed? Yes, on Cloud threads. Once a task reaches the cloud, the agent keeps working and its history is saved. Local threads stop when your Mac sleeps. Can I self-host Cloudroom? Yes. The open-source Rust Core runs on your own Ubuntu 24.04 server and installs with one command. No database is needed: session history stays on your machine. Managed hosting is optional. The setup guide is in the Core repo on GitHub. How does Cloudroom keep my code and keys safe? Each agent runs in its own isolated sandbox. It gets full admin rights inside it, but no access to other users or other sandboxes. Your agents call model providers directly. API keys you share go through a secure form and never appear in the chat. Our security page lists every measure and its limits.
