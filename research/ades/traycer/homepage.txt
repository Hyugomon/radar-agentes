We've got answers. Find answers to common questions about Traycer and its capabilities. What is Traycer? Traycer is a free, open-source desktop app for Mac, Windows, and Linux. It is a shared workspace where coding agents run side by side, each in its own worktree, with shared specs and tickets, and agents that message each other. Is Traycer open source? Yes. Traycer is fully open source. The code is at https://github.com/traycerai/traycer . Which coding agents does Traycer support? Traycer supports 22 coding agents and model providers. Coding agents: Claude Code, Codex, OpenCode, Cursor, Grok, Qwen Code, Kiro, Droid, Kimi, Copilot, Kilo Code, Amp, Devin, Pi, Hermes Agent, Oh My Pi, Reasonix, Antigravity, and Command Code. Model providers: Traycer Inference, OpenRouter, and Hugging Face. The coding agents run side by side, on the subscriptions you already have. The model providers supply the models they run on; Traycer Inference uses Traycer Credits. Is Traycer free? Yes. Traycer is free for individuals, including cloud sync and switching devices. Teams use Sync at $16 per user per month billed yearly, or $20 per user per month billed monthly, to share a task with the whole team. What does pay as you go mean? Running models through Traycer is paid with Traycer Credits, billed by use, and cloud sandboxes cost extra. Nothing else is metered on Free. More detail can be found here: https://docs.traycer.ai/account/pricing Where can I find support or join community? Join the community on Discord at https://discord.gg/DSpebDf6Gr , or browse the documentation at https://docs.traycer.ai . When do I need Sync? Individuals stay on Free, including cloud sync and device switching.
