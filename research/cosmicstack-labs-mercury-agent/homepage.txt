Every other channel works on all three operating systems. Spotted a cell that’s wrong? Open an issue and we’ll fix it. Questions Before you hand it the keys. Is Mercury free? Yes. Mercury is MIT-licensed open source. You bring the model: an API key, your ChatGPT Plus/Pro or GitHub Copilot subscription through OAuth, or a local Ollama model at zero cost. Mercury Cloud is optional. Where does my data live? On your machine, in ~/.mercury. Memory is a local SQLite database you can search, pause, or clear, and the agent ships no telemetry. Prompts go only to the model provider you configure. With Ollama Local, nothing leaves your machine. Could it do something destructive? In Ask Me mode, every file write, shell command, push, and scope change waits for your approval. Commands like sudo and rm -rf / are on a blocklist that never executes in any mode. Reads and writes are scoped to the folders you allow, and bots fail closed. How is it different from Claude Code or Codex? Those are coding sessions you open and close. Mercury is a personal agent that stays running: it has memory, schedules, persistent bots, and chat channels. It also includes Mercury Code, a full coding environment, for when you need one. Which platforms does it run on? Mercury Desktop runs on macOS (Apple Silicon and Intel), Windows and Linux. The Mercury runtime runs on the same three as a standalone binary or through npm (Node.js 22+), on Android via Termux, and on any cloud VM. Mercury Desktop can connect to any of them. Does it support MCP? Yes, since 1.5.0. Add a local or remote MCP server with mercury mcp add, allow the tools you want, and the agent can call them next to its ~50 built-in tools and 126+ skills. Every MCP call asks first in Ask Me mode. Up and running in about a minute. Mercury Desktop installs Mercury on your computer and keeps it updated. On a server, install it from the command line, answer the setup wizard, then run mercury up to keep it running for good.
