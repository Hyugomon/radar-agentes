FAQs View Docs How does pricing work? Hermes Agent is free and open source under the MIT license. Model providers and optional hosted services have their own pricing. You can use your own provider or connect to Nous Portal for model and tool credits; cloud hosting is optional. How do I get started? Download Hermes Desktop for macOS or Windows, or use the terminal installation command above. Follow the setup steps to connect a model provider, then start a conversation. For an always-on hosted agent, choose Deploy in the cloud. How do I chat with my agent? Use Hermes Desktop or the terminal, or connect a messaging platform such as Telegram, Discord, Slack, WhatsApp, Signal, or email. The documentation walks you through configuring each integration. Does my agent keep its data between sessions? Yes. Hermes stores conversations, memories, and skills so you can return to your work in a later session. Keep a backup of your Hermes data directory when moving to another computer. What happens when I stop my agent? Stopping a local agent ends its running process, but does not delete its saved conversations, memories, or skills. Start it again to continue. Tasks that need an active agent will not run while it is stopped; hosted agents are managed separately in Nous Portal.
