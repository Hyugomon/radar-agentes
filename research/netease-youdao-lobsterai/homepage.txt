LobsterAI（有道龙虾）是什么？ LobsterAI（有道龙虾）是网易有道出品的开源桌面 AI Agent，定位为全场景办公助手。它安装在你的电脑上，可以连接本地文件、终端、浏览器和项目，帮你完成文档处理、数据分析、应用开发、调研报告和定时任务等工作。 LobsterAI 和 OpenClaw 是什么关系？ LobsterAI 基于开源 Agent 框架 OpenClaw 构建，可以持续接入 OpenClaw 生态中的 Skills、工具、插件。在此基础上，LobsterAI 提供一键安装的桌面客户端，并支持通过微信、企业微信、钉钉、飞书等 IM 远程指挥。 LobsterAI 开源吗？ 开源。LobsterAI 的代码以 MIT 协议发布在 GitHub（netease-youdao/LobsterAI），能力透明可查，权限、数据与执行链路都可以审计。 查看 GitHub 仓库 LobsterAI 支持哪些操作系统？ 支持 macOS（Apple 芯片与 Intel 芯片）和 Windows。下载页可以手动选择对应的安装包，也能找到历史版本和 Mac 芯片类型的识别方法。 前往下载页 LobsterAI 可以使用哪些 AI 模型？ LobsterAI 提供官方套餐模型，已接入 DeepSeek、Kimi、GLM、MiniMax 等国内顶级模型，无需自己申请 API Key 即可直接使用。也可以在「设置 → 模型」中添加自定义模型，填入 DeepSeek、Anthropic、OpenAI 等服务商的 API Key；或通过 Ollama 运行本地模型，在不联网的情况下处理任务。 查看模型配置指南 可以用手机远程让 LobsterAI 干活吗？ 可以。在 LobsterAI 中配置 IM 机器人后，就能通过微信、企业微信、钉钉、飞书等聊天工具，给电脑上的
